# Lista de Compras

**Aluno:** Stela de Oliveira
**Atividade:** Lista de Compras com AsyncStorage

App mobile de lista de compras desenvolvido com React Native e Expo.
Permite adicionar, marcar como comprado e excluir itens, com persistência local via AsyncStorage.

## Funcionalidades

- Adicionar itens com nome e categoria
- Marcar itens como comprados (com texto riscado)
- Excluir itens individualmente
- Limpar toda a lista
- Contador de itens pendentes e comprados
- Dados salvos localmente com AsyncStorage

## Como executar

**Pré-requisitos:** Node.js instalado e Expo Go no celular

```bash
npm install
npx expo start
```

Escaneie o QR code com o Expo Go (Android) ou com a câmera (iOS).
